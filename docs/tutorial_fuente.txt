En este tutorial se ilustrarán los pasos que se requieren para desplegar un servidor de streaming para
los dispositivos ESP32-CAM-MB y ESP32-XIAO-S3 que emplean la cámara OV2640.
El tutorial se enfoca en la creación de tanto del servidor de streaming como de aplicaciones que
empleen código nativo (C++) o Python para realizar el procesamiento de imágenes en OpenCV que
se capturen desde los dispositivos ESP32-CAM-MB y ESP32-XIAO-S3.
¿Por qué emplear este tipo de dispositivos?
Resulta a más de novedoso muy práctico desarrollar determinados tipos de proyectos con estos
dispositivos en virtud de sus características. En la Tabla 1 podemos observar las principales
características de los mismos:

Instalación de herramientas

Como primer paso debemos instalar las herramientas necesarias para desarrollar la aplicación en
Arduino, ya que el microcontrolador ESP32 es compatible con este entorno. En esta sección
presentarán paso a paso los entornos y librerías que deben instalarse previamente.

1.1

Arduino IDE

El entorno de desarrollo que se utilizará es Arduino IDE | 2.3.6. Para instalarlo en sistema operativo
basta con descargar la versión correspondiente desde el sitio oficial de Arduino® [enlace de
descarga]. Una vez descargada la versión correspondiente al sistema operativo que estemos
empleando, descomprimimos el fichero en la carpeta de nuestra preferencia, y ejecutamos el
comando arduino-ide (en este tutorial se trabajará para sistemas GNU/Linux, siendo muy similar al
caso de Microsoft Windows® para iniciar el entorno.
En el caso de usar distribuciones basadas en GNU/Ubuntu 24.04, se puede presentar el siguiente
error de seguridad:

Figura 1: Error de ejecución del IDE Arduino 2.3.6 en sistemas operativos basados en
GNU/Ubuntu 24.04

Esto se debe a que el IDE de Arduino debe ejecutarse como usuario sin privilegios de administrador
(root) y esto entra en conflicto con el nuevo sistema de seguridad implementado en estos sistemas
operativos (AppArmor).
Para solucionar este problema existen diversas opciones, sin embargo, podemos simplemente crear
un perfil AppArmor para el IDE de Arduino. Para ello debemos crear el archivo
usr.local.bin.arduino en la ruta /etc/apparmor.d/ y colocar el siguiente código dentro:
Tabla 2: Código para la creación de un perfil AppArmor para la correcta ejecución del IDE de
Arduino. Fuente: mariovaldez [https://github.com/arduino/arduino-ide/issues/2429#issuecomment2099775010]
abi <abi/4.0>,
include <tunables/global>
profile arduino /home/vlarobbyk/aplicaciones/arduino-ide_2.3.6_Linux_64bit//arduino-ide
flags=(unconfined) {
userns,
include if exists <local/arduino>
}

Es importante observar que el código resaltado con amarillo corresponde a la ruta donde se haya
instalado el IDE de Arduino, ya sea vía descarga del comprimido en formato ZIP (la más cómoda) o
vía instalación de paquete. Debe verificar también el nombre del archivo ejecutable, en el caso de
este tutorial es arduino-ide.
Una vez creado el archivo, recargamos todos los perfiles del sistema de protección AppArmor con
el siguiente comando y volvemos a cargar sin problema el IDE de Arduino:
sudo service apparmor reload

1.2

Acceso a puertos

El IDE de Arduino no podrá acceder al puerto USB donde está conectado el dispositivo si antes no
damos acceso a dicho puerto al usuario del sistema operativo que ha lanzado el IDE.
Para brindar este acceso, debemos añadir al usuario actual al grupo dialout a través del siguiente
comando (que debe ser ejecutado como root):
sudo usermod -a -G dialout vlarobbyk

Donde vlarobbyk corresponde al usuario actual. Usted deberá reemplazarlo por su nombre de
usuario y reiniciar el computador para que los cambios tengan efecto.

1.7

Carga del servidor de video streaming

Dentro del IDE de Arduino ya existen varios ejemplos para el manejo de diversos dispositivos. Por
ello, emplearemos como base el ejemplo para manejo de cámaras en ESP32. Deberemos abrir la
siguiente ruta:
File → Examples → ESP32 → Camera → CameraWebServer
Una vez abrimos el ejemplo, se cargará automáticamente todo el código que se requiere para lanzar
el servidor de streaming de video.
Debemos modificar la línea que corresponde con el modelo que tenemos instalado, en este caso
comentamos la línea de la cámara que viene por defecto y quitamos el comentario de la siguiente
línea:
#define CAMERA_MODEL_XIAO_ESP32S3 // Has PSRAM

En el caso de usar el modelo ESP32-XIAO-S3. Si por el contrario, usamos el modelo ESP32-CAMMB, deberemos quitar el comentario a la siguiente línea:

#define CAMERA_MODEL_AI_THINKER // Has PSRAM

Una vez realizado este cambio, debemos colocar las credenciales de la red WIFI con la que estamos
trabajando, a fin de que la tarjeta pueda desplegar el servidor de video streaming. Modificaremos las
siguientes líneas, de acuerdo a los datos de nuestra red (nombre de la red y contraseña,
respectivamente):
const char *ssid = "**********";
const char *password = "**********";

Guardamos el archivo en la carpeta donde se vaya a almacenar el proyecto y damos clic en el botón
“Verify”

.

Ello permitirá verificar que se compile el archivo sketch de Arduino. Posterior a esto, deberemos
dar clic en el botón “Upload”

para que el código sea cargado en la tarjeta ESP32.
